# Winter Snowman — учебная практика

Учебный проект по курсу «Программирование». Консольное графическое приложение на C++ с использованием SFML 3.

## Что реализовано

- Анимированный снеговик (3 шара, шляпа, шарф, морковный нос)
- Руки-ветки из фрактальных деревьев, управляемые с клавиатуры
- Снегопад со случайной генерацией частиц
- Фрактальные деревья на фоне (рекурсия)
- Прыжок по пробелу

## Управление

| Клавиша | Действие |
|---------|----------|
| `↑ / ↓` | Поднять / опустить руки |
| `→ / ←` | Больше / меньше снега |
| `Space`  | Прыжок |
| `Esc`    | Выход |

## Сборка

Требуется SFML 3 и CMake

```bash
g++ main.cpp -o snowman -std=c++17 \
  -I/opt/homebrew/include \
  -L/opt/homebrew/lib \
  -lsfml-graphics -lsfml-window -lsfml-system
```
